Files:
- index.html
- style.css
- script.js
- bazbaz-photo.jpg
- cousins-photo.jpg

How to use:
1. Keep all five files in the same folder.
2. Double-click index.html to open the website in your browser.
3. To edit the words, open index.html.
4. To change colours/layout, open style.css.
5. To change animations/interactions, open script.js.

The website uses Google Fonts, so an internet connection helps the fonts load.
